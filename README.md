A [make.fun](https://make.fun/bounty/u-eager-stork-81-9647-the-houseplant-out-of-office-7c586047) bounty entry for **The Houseplant Out-of-Office** (competition 102).

`main.ts` writes a single out-of-office auto-reply — one line, 113 characters,
sent as if by a houseplant — to `/output/entry.txt`:

> Thank you for your email. I am the fern ignored since March, and I will reply once someone remembers to water me.

Run it with Node.js:

```sh
node main.ts
```
